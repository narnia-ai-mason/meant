<h1 align="center">meant</h1>

잘못된 자판으로 친 단어가, 쓰려던 말이 됩니다.

한영 전환을 깜빡하면 `dkssud`가 되고, `ㅗ디ㅣㅐ`가 됩니다. 단어를 지우고 다시 치는 수밖에 없죠. meant는 그 단어를 보고, 원래 치려던 쪽을 보여줍니다.

meant는 Mac 메뉴 막대에 있습니다. 글을 쓰다 스페이스를 누르면, 방금 친 단어가 잘못된 자판처럼 보일 때 캐럿 옆에 작은 제안이 뜹니다. `dkssud` → `안녕`.

Enter로 바꿉니다. 바꾸면 입력기도 그쪽으로 맞춰집니다.

## 설치

1. [Releases](https://github.com/narnia-ai-mason/meant/releases)에서 최신 `meant-*.dmg`를 받습니다.
2. 디스크 이미지를 열고 **meant**를 응용 프로그램으로 끌어다 놓습니다.
3. 응용 프로그램에서 meant를 엽니다. 메뉴 막대에 나타납니다.

macOS 14 이상. Gatekeeper가 막으면 Finder에서 **열기**로 한 번 열어 주세요.

## 써보기

1. 메뉴 막대 아이콘에서 **Settings**를 엽니다.
2. **Accessibility**와 **Input Monitoring**을 허용합니다. 하나는 단어를 바꾸고, 하나는 스페이스를 봅니다.

그다음 아무 입력란에서나 글을 쓰세요. 한영을 깜빡한 단어 뒤에서 스페이스를 누르면 제안이 뜹니다.

Enter로 바꿉니다. Tab은 이번과 다음부터 그 단어를 건너뜁니다. Esc는 닫습니다.

바로 바꾸고 싶으면 **⌃⌘M**을 누르세요. 단축키는 Settings에서 바꿀 수 있습니다.

제안이 계속 거슬리면 Tab으로 넘겨 두세요. Settings의 **Ignore**에도 직접 넣을 수 있습니다.
